# 🧭 Universal Layihə Bələdçisi Sistemi (Project Navigator)

Bu sistem istənilən proqramlaşdırma layihəsində faylların və papkaların nə işə yaradığını **Kitab Mündəricatı** şəklində təqdim edən universal avtomatlaşdırma alətidir.

## 🚀 Başqa Layihələrdə Necə İstifadə Etməli?

1. Bu `beledci` qovluğunu istənilən başqa layihənin kök qovluğuna kopyalayın.
2. Qovluqda `beledci_generator.py` skriptini işə salın:
   ```bash
   python beledci/beledci_generator.py
   ```
3. Skript avtomatik olaraq:
   - `beledci/MUNDERICAT.md` faylını yaradacaq/yeniləyəcək.
   - `beledci/beledci.html` İnteraktiv Veb Panelini yaradacaq.
4. Xüsusi təsvirlər əlavə etmək üçün `beledci/descriptions.json` faylına papka/fayl adlarını və onların izahını yaza bilərsiniz.

# MasterDeploy UI Audit Hesabatı - 2026-07-29

Bu sənəd MasterDeploy (MD) layihəsinin React/Vite UI tətbiqi ilə Coolify PHP Livewire kod bazası arasındakı 1-ə-1 funksional boşluqları və əskikləri sənədləşdirir. **Növbəti agentlər bu sənədi oxumalı, buradakı əskikləri tamamlamalı və iş bittikdən sonra öz tarixləri ilə hesabat yeniləməsi etməlidirlər.**

---

## 1. Mövcud Fayllar üzərində Düzəlişlər, yoxsa Yeni Fayllar?
*   **Mövcud Səhifələrin Modifikasiyası:** Mövcud olan `ServerDetailPage.tsx`, `ServerProxyPage.tsx`, `TerminalPage.tsx` və `ServerChartsPage.tsx` kimi səhifələrin strukturunu qoruyaraq, onların daxilinə real formaları, inputları, state-ləri və api inteqrasiyalarını yazmaq.
*   **Yeni Component-lər:** Hər tabın (məsələn, `Private Key Selector`, `CA Certificate Form`, `Docker Swarm Config`, `Proxy Settings Forms`) idarəetməsini tək bir faylda böyütməmək üçün `ui/src/components/server/` qovluğunda yeni modullar yaratmaq.

---

## 2. Müəyyən Edilmiş Əskiklər və Boşluqlar (Audit Qeydləri)

### A. Server General Configuration (Səhifə: `ServerDetailPage.tsx` / `show.blade.php`)
Coolify-ın orijinal `livewire/server/show.blade.php` və `Show.php` fayllarında mövcud olan, lakin bizim React UI-da tamamilə əskik olan və ya statik olan sahələr:
*   [x] **Bulud Provayderi İdarəetməsi:** Hetzner, Vultr və DigitalOcean API-ləri vasitəsilə server statusunu yoxlamaq (HetznerServerStatus, VultrInstanceStatus, DigitalOceanDropletStatus) və "Power On/Off" (Enerji qoş/söndür) idarəetmə düymələri.
*   [x] **Server IP & Giriş sahələri:**
    *   Wildcard / Private IP ünvanları üçün xüsusi inputlar.
    *   SSH port (default 22) və SSH istifadəçi adı (default root).
*   [x] **Server resurs limitləri:**
    *   [x] `concurrent_builds` (Eyni anda icra ediləcək build limiti) input sahəsi.
    *   [x] `unreachable_count` və `unreachable_notification_sent` status göstəriciləri.
*   [x] **Sentinel (Monitorinq Agent) sazlamaları:**
    *   Sentinel qoşulma statusu, quraşdırma düyməsi və avtomatik yenilənmə tokeni sahələri.
*   [x] **Docker Sazlamaları:**
    *   [x] Docker quraşdırılma statusu, versiya yoxlanışı və yenidən quraşdırma düyməsi.

### B. Server Sub-Tabs (Səhifə: `ServerConfigurePage.tsx` / Livewire qovluqları)
Coolify `livewire/server/` altındakı digər tabların qarşılığı bizim UI-da yoxdur və ya tamamilə boşdur:
*   [x] **Private Key (Özəl Açar) İdarəetməsi:** Serverə bağlı olan SSH Private key-in seçilməsi (`PrivateKey` selector Dropdown) və yeni açar əlavə etmə linki.
*   [x] **CA Certificate (Sertifikatlar):** Müvafiq CA Certificate məlumatlarının daxil edilməsi, redaktəsi və validation qaydaları.
*   [x] **Docker Swarm Konfiqurasiyası:** Swarm rejiminə keçid, menecer/worker düymələri, cluster token və join əmrləri forması.
*   [x] **Proxy Settings (Səhifə: `ServerProxyPage.tsx` / `proxy.blade.php`):**
    *   [x] Proxy növü (Traefik, Caddy) və proxy port konfiqurasiyaları.
    *   [x] Proxy konfiqurasiya faylının Monaco Editor (kod redaktoru) vasitəsilə birbaşa dəyişdirilməsi.
    *   [x] Proxy dynamic configuration formları.
*   [x] **Security (Təhlükəsizlik) formları:**
    *   [x] Firewall aktiv/deaktiv, SSH port və təhlükəsizlik qaydalarının (iptables / ufw) idarəedilməsi düymələri.
    *   [x] OS updates (Patches) yoxlama, listləmə və update düymələri.
    *   [x] SSH Terminal giriş icazəsinin şifrəli təsdiqlə idarə olunması.
*   [x] **Resources & Log Drains:**
    *   [x] Log drains (sistem loglarının kənar serverə ötürülməsi) aktiv/deaktiv, server url, transport tipi (udp, tcp, tls) forması.
    *   [x] Managed və unmanaged container resurs siyahısı və start/stop/restart əməliyyatları.

## 3. Növbəti Agent Üçün Təlimat (Mütləq Qayda)
1. Bu fayl daxilindəki boşluqları sırayla götürərək Coolify-ın local olaraq `coolify-source/app/Livewire/Server/` altındakı PHP fayllarında olan form sahələrini, düymələri və input validation limitlərini oxuyun.
2. Bu limitlərə və məntiqlərə uyğun olaraq React frontend komponentlərini və API çağırışlarını yazın.
3. Hər hansı bir boşluğu tamamladıqdan sonra bu sənədi yeniləyərək qarşısına `[x]` qoyun.
4. Gördüyünüz işləri yekunlaşdırdıqda həmin günün tarixi ilə yeni bir audit/hesabat sənədi yaradın və ya bu sənədə yeni bölmə əlavə edin.
